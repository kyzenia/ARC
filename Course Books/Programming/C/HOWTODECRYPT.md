# How to decrypt

There are some files in this directory that ends with `.yabgu`. Those files are encrypted using my own custom file encryption tool [Yabgu](https://github.com/kyzenia/arc-yabgu).

You can decrypt them using Yabgu with the following seed and key combinations:

- For `Beej's Guide`: Seed: 353, Key: 353
- For `C How to Program`: Seed: 353, Key: 353
- For `Modern C`: Seed: 353, Key: 353
